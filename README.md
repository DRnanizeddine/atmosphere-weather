# 🌦️ Atmosphere - Real-Time Weather Dashboard

A responsive weather web application built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## ✨ Features
- 🔍 **Global City Search**: Search for weather conditions across cities worldwide.
- 📍 **Geolocation Support**: Instantly detect location weather.
- 🌡️ **Unit Switcher**: Toggle easily between Celsius (°C) and Fahrenheit (°F).
- 📅 **5-Day Forecast**: Plan ahead with clean forecast breakdowns.
- 🕒 **Recent Searches History**: Quick tap access to recently queried cities.
- 🌙 **Dark/Light Mode**: Automatic theme detection with smooth manual toggles.

## 🚀 Quick Start
1. Clone repository:
   ```bash
   git clone https://github.com/<your-username>/atmosphere-weather.git
   ```
2. Open `index.html` directly in your browser!
